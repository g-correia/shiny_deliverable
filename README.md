# Shiny App on Malaria Cases

This Shiny application provides an interactive visualization of Malaria cases in the Northern region of Brazil for 2017. The application was developed as part of academic training in statistical programming and reproducible research practices.

The original dataset in DBF format used for app input (NOTIPO17). 

To see app, run file shiny_malaria.R.

Alternatively, the app can also be accessed via: https://biblioteca.shinyapps.io/shiny_malaria/
